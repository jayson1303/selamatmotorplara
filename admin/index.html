Petunjuk Pengelolaan Data Dealer

Selamat datang di Dashboard Admin SELAMATMOTORPLARA. Semua data yang Anda ubah di sini akan langsung terhubung ke database Google Firebase (Firestore & Storage) dan otomatis diperbarui di landing page dealer tanpa perlu edit kode HTML.

  • Kelola Motor & Kredit: Tambah varian warna motor, upload foto motor, atur harga cash, dan atur tabel simulasi DP/Tenor/Cicilan.
  • Fitur Import: Anda dapat mengimpor file Excel PL JULI 2026 DP BESAR.xls atau menginisialisasi ke-45 motor sekaligus dengan 1 klik!
  • Template WhatsApp: Sesuaikan format chat order yang masuk ke WhatsApp sales agar informasi motor, warna, DP, dan tenor langsung rapi terformat.
